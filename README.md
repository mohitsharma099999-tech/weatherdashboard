# Weather Dashboard

A simple weather dashboard website that provides real-time weather updates for cities by fetching data from weather APIs.

## 📋 Description

This project is a web-based weather dashboard that allows users to check current weather conditions for various cities. It retrieves live weather data through API calls and displays it in a clean, user-friendly interface.

## ✨ Features

- Real-time weather updates for cities
- Fetch weather data from external APIs
- Simple and responsive user interface
- Display of current weather conditions
- Search weather by city name

## 🛠️ Technologies Used

- **HTML** (`index.html`) - Structure of the web page
- **CSS** (`style.css`) - Styling and layout
- **JavaScript** (`script.js`) - Logic and API integration

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, etc.)
- An API key from a weather service provider (e.g., OpenWeatherMap)
